## Overview

A lightweight Java application designed to demonstrate core OOP principles including inheritance, method overriding, overloading, and polymorphism. It seamlessly manages banking operations across savings, checking, and investment accounts, enforcing customized rules for transactions, interest rates, and commission calculations.
